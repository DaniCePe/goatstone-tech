# Goatstone Tech

Public website for Goatstone Tech (West Chicago, IL): IT liquidation, data destruction following NIST SP 800-88 Rev. 2, asset recovery, and remarketing.

Static site. Layout adapted from the WebBelt/WebBuckle codebase; visual style is the Goatstone paper format from the Styles Guide (assets/goatstone.css): cream ruled paper, taped cards, Steelfish headlines, Share Tech body, Handmade Alphabet notes. Hosted with GitHub Pages.
